# GreenOps MVP

Responsive landscaping operations prototype for desktop, tablet, iPhone, and Android browsers.

## Run locally

```bash
python3 -m http.server 8080
```

Then open `http://localhost:8080`.

## Included
- Owner dashboard
- Schedule calendar
- Customer management
- Jobs and job detail
- Estimates and invoices
- Crew view
- LocalStorage demo persistence
- Responsive mobile navigation
- PWA manifest
